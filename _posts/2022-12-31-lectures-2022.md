With the end of the COVID19 pandemic, very  glad to get back to face to face training courses.

__Feb__: In Cheltenham, UK; the first course using the Home SDR Lab format with 
a raspberry pi 4 computer provided for all the participants.  Unfortunately
raspberry pi SBCs has become really hard to source, so while enough hardware 
was bought, it was tricky and at a higher cost that budgeted.

As a concequence, the Raspberry Pi computer idea had to be abandoned 
and the SDR course re-arranged to use an Ubuntu live boot disk.

__May__: In San Jose, CA; a modification of the Home SDR Lab format using an 
Ubuntu boot disk for the training room computers. By providing a boot disk
in advance the client was able to test it out on all the machines before hand,
which was a big help.

Also, by using training room computers, there was no connection to the internal 
network which assuaged any security concerns.  This couse was over subscribed and
was run for 2 groups on succeesive weeks.
